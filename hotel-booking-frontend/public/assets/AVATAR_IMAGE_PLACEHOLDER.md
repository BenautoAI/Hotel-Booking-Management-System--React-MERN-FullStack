# Avatar Image Placeholder

## Required Image

Please place your avatar image file in this directory with the following specifications:

- **Filename**: `avatar.png`
- **Location**: `hotel-booking-frontend/public/assets/avatar.png`
- **Recommended Size**: 256x256px or 512x512px (for retina displays)
- **Format**: PNG with transparency (if desired)
- **Content**: The anime-style avatar shown in the design screenshot

## Usage

This image will be displayed in the footer's Company Info section as a circular avatar with a gradient border effect.

## Note

The Footer component is already configured to load this image from `/assets/avatar.png`. Once you place the image file in this directory, it will automatically display in the footer.
